# Guilded 8.3.0 — Simpler navigation and optional automation

Candidate for the October 30 launch. Provider availability is separate from
source readiness. Acceptance: [V8_3_0_RELEASE_ACCEPTANCE.md](V8_3_0_RELEASE_ACCEPTANCE.md).

- Website: direct My Guilded and leaderboard navigation, clearer edition
  context, season boundaries and weekly-versus-selected-period explanations.
  Short EN/FR member quick starts link separately to officer/self-hosting help.
- Companion: Home with a state-specific next action, direct guild/ranking
  shortcuts, simpler navigation and optional tools. Web sync is retained for
  browser/non-Windows use; Windows provides local background watching. Both
  still need WoW to save addon data with reload/logout.
- Optional automation: private member weekly recap DMs, approved weekly
  questions and opt-in vacancy alerts. Quiet hours, pause, delivery state,
  permission/consent checks and duplicate suppression apply. Everything begins
  off; configure it with `/automation`. No automatic awards.
- Private Battleground organization: EN/FR Create, Join, My groups and Upcoming
  controls, one-off scheduling, owned-character edition/level checks and
  waiting lists. Retail Blitz has a reviewed duo/healer queue policy. Other
  formats remain explicitly planning-only until their queue rules are verified.

## Limits and testing

BG capture and statistics are not included. Normal-realm/faction choices are
player declarations, not verified game telemetry. Hardcore BG remains disabled.
Game acceptance is **NOT RUN — timing waived until after launch** by the owner;
Forever tests cannot precede its November 4 opening. This is not a claim that
native, game or multi-account tests passed. Security, migration/recovery, CI and
non-game checks remain release gates. Frozen 8.2.0 provider files are unchanged.

## Français

- Navigation plus simple : Mon Guilded, classements, édition choisie et périodes
  visibles. Guide membre EN/FR court, séparé des références officiers/hébergement.
- Compagnon : accueil avec prochaine action, raccourcis et outils facultatifs.
  La synchronisation Web reste disponible; Windows surveille les fichiers en
  arrière-plan. WoW doit toujours enregistrer via recharge/déconnexion.
- Automatisations facultatives : bilan privé, question hebdomadaire et places
  disponibles, avec accord, silence, pause et contrôle des doublons. Désactivées
  par défaut; `/automation` permet de les configurer. Aucun point automatique.
- Organisation JcJ privée : formulaires, inscriptions personnelles et attente.
  Les formats de file non vérifiés restent en planification seulement.

Les tests en jeu sont reportés après lancement, **non exécutés**, et ne sont pas
présentés comme réussis. Aucune capture ni statistique JcJ n'est publiée.
