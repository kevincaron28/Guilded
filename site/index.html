DEFAULT FOR DISCORD SYNC

Sync from your browser.

Start with your guild’s online companion. Pair once on this browser/device and choose your saved-data and addon folders. After playing, reload WoW and click Sync now.

Supported browsers remember both folders and Sync now uploads data and saves standings together. Reload WoW again to load them. The optional Windows app adds automatic file watching, background syncing and PoE2 log tracking—especially useful for leaders and officers. Other browsers can upload and download files manually.

Ask your guild officer. Never enter a token or pairing code on this page.

A few useful answers.

Do all guildmates need their own bot?

No. One owner hosts the bot and database. Each player installs the addon and optionally connects a companion with a personal pairing code.

Is hosting included?

The free hosted pilot accepts a small number of guilds. Adding Guilded requests access; KCaron must approve your server before setup or sync works. An invitation does not guarantee a place. See the pilot steps, or use the owner guide for independent hosting. Providers may offer free tiers, with limits and availability that you must check.

Do I have to donate?

No. Financial support is optional and never buys approval, priority or extra permissions. Support information.

Can I use both desktop and browser companions?

Pairing a new companion replaces the previous link for that account. Choose one mode while testing; switching requires a fresh code.

Where are the raid markers and boss plans?

Raid tools were removed from Guilded v6. A separate leader addon is future work and is not available to download here.
