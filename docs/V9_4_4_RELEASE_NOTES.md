# Guilded 9.4.4 — release notes (20 November 2026)

Published 20 November 2026. Protocol 2, WoW Forever only. Bot changes are already live.

Real-client checks: docs/V9_4_4_RELEASE_ACCEPTANCE.md.

## What changes for members

- **Setup:** a short first-time setup window (`/guilded setup`) for the companion and the Guilded chat tab.
- **Officers:** the promotion window knows alts and moves them to the Alt rank.
- **Crafting:** easier to browse, with favourites and names in your language.
- **Characters:** every character is matched by its game id, so two characters with the same first name are never mixed up.

## In short (English)

Guilded 9.4.4: a first-time setup, alts in the promotion window, a cleaner Crafting tab, and exact character matching.

## En bref (français)

Guilded 9.4.4 : une configuration de départ, les alts dans la fenêtre de promotion, un onglet Artisanat plus clair et une correspondance exacte des personnages.
