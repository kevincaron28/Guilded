# Self-hosted typefaces

- Inter Variable: https://rsms.me/inter/font-files/InterVariable.woff2 — `inter-latin.woff2`. Official font and SIL Open Font License: `INTER-LICENSE.txt`.
- Source Serif 4 Italic, weight 400: exact font URL returned by https://fonts.googleapis.com/css2?family=Inter:wght@400..700&family=Source+Serif+4:ital,wght@1,400&display=swap — `source-serif-latin.ttf`. Adobe's SIL Open Font License is in `SOURCE-SERIF-LICENSE.md`.

Retrieved 19 October 2026. The files are served locally with `font-display: swap`. They include French glyphs. The filename “latin” is a presentation asset name, not a claim that the original complete font was subset.
