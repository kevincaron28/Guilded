# Support Guilded

Guilded's addon is free for noncommercial use. The shared Discord bot is a small,
free hosted pilot: **KCaron must approve each Discord server before it can use
the bot.** [Request access](HOSTED_PILOT.md).

Voluntary support helps cover hosting, backups, maintenance and future capacity.
It is never required to download the addon or request access. A contribution does
not buy approval, priority in the queue, extra permissions or guaranteed uptime.

**The official support link is not available yet.** Until it is published here,
there is no payment step in Guilded's setup. You can also help by reporting clear
bugs and sharing feedback through [GitHub](https://github.com/kevincaron28/Guilded/issues).

## Français

Le pilote hébergé est gratuit, mais **KCaron doit approuver chaque serveur Discord
avant son activation**. Un soutien financier est toujours facultatif et ne donne
ni accès automatique, ni priorité, ni permissions supplémentaires. Le lien officiel
de soutien sera publié ici lorsqu'il sera prêt. Aucun paiement n'est nécessaire
pour installer l'addon ou demander l'accès au bot.
