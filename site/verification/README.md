# Google Search Console ownership files

Place an owner-authorized Google HTML verification file here with its exact
original filename and content. The site build accepts only filenames matching
`google` plus 8–64 lowercase hexadecimal characters plus `.html`, and requires
the exact `google-site-verification: <filename>` content, ignoring surrounding
whitespace. It copies those files to the public root on the shared Worker.

This directory does not create Search Console properties, grant ownership,
change DNS, or contain credentials. Add only verification files for properties
and account identities explicitly approved by the owner. This README is not
copied into public output.

Canonical sitemaps already exist at https://kcaron.top/sitemap.xml and
https://guilded.kcaron.top/sitemap.xml. Submit the matching sitemap after
ownership verification. A successful sitemap submission does not guarantee
Google indexing or search rankings.
