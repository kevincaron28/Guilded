# Guilded 7.4.0 Release

Guild and roster tools for Forever, Classic Era/Hardcore, TBC Anniversary,
Mists Classic and Retail, with separate guild contexts in one Discord server.
Protocol remains 2; existing pairing credentials and SavedVariables are preserved.

- Signed-in roster, crafting, raid-team, character-history and group pages, with
  officer access checked against the selected guild and edition.
- In-game roster action plans for notes, ranks and removals. Review the exact
  members first; each action needs a separate hardware click and verification.
- Desktop and CLI migration of GRM SavedVariables into a local history archive,
  with preview, import and undo. Private history is excluded by default. This
  does not change Discord character ownership or EPGP balances.
- Edition-aware raid buff coverage, native profession/finder shortcuts, optional
  availability sharing and local activity summaries; Retail key sharing is opt-in.
- Forever character menus retain first and last names. Large character lists are
  paginated, core editors recheck permissions, and backup-page changes are atomic.
- Claude's Discord walkthrough corrections and sourced raid-loot reference are
  included, alongside stale-form, privacy, import-validation and response-timing fixes.

Install the ZIP matching your game edition. Unsuffixed ZIPs are for Forever.
The Windows companion supports every edition. Its installer is unsigned.

benchmarks are provisional; this is not an official Raider.IO or Blizzard rating.
