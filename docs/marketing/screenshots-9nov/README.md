images are on the website's features page (`site/images/addon/`, webp). These JPG copies are for
the CurseForge gallery, social media and the Store listing.

Size: the window shots are 778 × 585 px as captured (the game window was small). They are not
upscaled, because enlarging adds blur, not detail. For a sharper CurseForge gallery, retake them at
1280 × 960 or more. `15` has one line blurred (a non-guild player's public yell). The old-wording
announcements shot (`12`) is deliberately left out.
