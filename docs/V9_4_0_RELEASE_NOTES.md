# Guilded 9.4.0 — release notes (19 November 2026)

**The owner's 9.4 list.** Published 19 November 2026. Protocol 2, WoW Forever only. Bot changes are already live (migrations applied on the live bot).

Real-client checks: docs/V9_4_0_RELEASE_ACCEPTANCE.md. 9.4.0 is not yet confirmed on real clients.

## What changes for members

- **Layer:** its own button, with the auto-invite switch on the page; the layer switches finally work.
- **Crafting:** a new crafting window to request items, follow your requests and see a shopping list for what you claimed.
- **Officers:** a Promote next key, and a do-not-invite tag in the invite panel.
- **Companion:** steadier uploads, no duplicate sends, clearer update messages.

## In short (English)

Guilded 9.4.0: a Layer button that works, a new crafting window, a Promote next key, and steadier companion uploads.
