<h1 id="install-title">Install <em>Guilded.</em></h1>
<p>Two small pieces, both free: the <strong>addon</strong> for World of Warcraft (required) and the <strong>companion</strong> for Windows (recommended, it links you to Discord). About ten minutes, no technical knowledge needed.</p>
<p class="small">Already installed? Go to <a href="/guides/link/">Link your character</a>.</p>
</section>

<section class="start-path" aria-labelledby="addon-title">
<h2 id="addon-title">Part 1 · The addon (required)</h2>
<ol class="start-list">
<li class="start-step"><div class="start-head"><span class="start-num" aria-hidden="true">1</span><h3>Download it from CurseForge</h3></div><p>Open the <a href="https://www.curseforge.com/wow/addons/guilded">Guilded page on CurseForge ↗</a>. Choose the file marked for <strong>WoW Forever</strong> and press <strong>Download</strong>. You get a ZIP file. If you use the CurseForge app, press <strong>Install</strong> instead and skip to step 3.</p><figure class="guide-shot"><img class="guide-shot-img" src="/assets/guides/install-curseforge-page.png" alt="The Guilded page on CurseForge with the WoW Forever file and its Download button" loading="lazy"><figcaption><span class="shot-soon">Screenshot coming soon: </span>the CurseForge page, Download button for the Forever file.</figcaption></figure></li>
<li class="start-step"><div class="start-head"><span class="start-num" aria-hidden="true">2</span><h3>Put it in the AddOns folder</h3></div><p>Close WoW completely. Open the folder of the Forever game you launch (in Battle.net: <strong>Options → Show in Explorer</strong>), then open <code>Interface</code> and <code>AddOns</code>. Extract the ZIP there. When it worked you see <code>AddOns\Guilded\Guilded.toc</code>, <strong>not</strong> a second <code>Guilded</code> folder inside <code>Guilded</code>.</p><figure class="guide-shot"><img class="guide-shot-img" src="/assets/guides/install-addons-folder.png" alt="Windows Explorer showing Interface, AddOns, Guilded with the Guilded.toc file inside" loading="lazy"><figcaption><span class="shot-soon">Screenshot coming soon: </span>Explorer in Interface\AddOns with Guilded.toc visible.</figcaption></figure></li>
<li class="start-step"><div class="start-head"><span class="start-num" aria-hidden="true">3</span><h3>Turn it on in game</h3></div><p>Start WoW. On the character screen press <strong>AddOns</strong> and make sure <strong>Guilded</strong> is ticked. If the game asks, tick <strong>Load out of date AddOns</strong> too. Then enter the game.</p><figure class="guide-shot"><img class="guide-shot-img" src="/assets/guides/install-ingame-addons-list.png" alt="The WoW AddOns list with Guilded ticked" loading="lazy"><figcaption><span class="shot-soon">Screenshot coming soon: </span>the AddOns list at character select, Guilded ticked.</figcaption></figure></li>
<li class="start-step"><div class="start-head"><span class="start-num" aria-hidden="true">4</span><h3>Check that it works</h3></div><p>In game, type <code>/guilded</code> or click the gold coin on the minimap. The Guilded window opens: that is all for the addon. It already works on its own, even without Discord.</p><figure class="guide-shot"><img class="guide-shot-img" src="/assets/guides/install-ingame-window.png" alt="The Guilded window open in game, with the minimap coin visible" loading="lazy"><figcaption><span class="shot-soon">Screenshot coming soon: </span>the Guilded window and the gold minimap coin.</figcaption></figure></li>
</ol>
</section>

<h2 id="companion-title">Part 2 · The companion (Windows, recommended)</h2>
<p>The companion sends your saved game data to Discord and the website, and it is what links your characters to your Discord account. It works on Windows only. No Windows PC? You can still link: see <a href="/guides/link/#no-companion">Link your character</a>.</p>
<ol class="start-list">
<li class="start-step"><div class="start-head"><span class="start-num" aria-hidden="true">5</span><h3>Get it from the Microsoft Store</h3><span class="start-tag required">Recommended</span></div><p>Open the <a href="https://apps.microsoft.com/detail/9N680XX3QFL9">Guilded Companion page in the Microsoft Store ↗</a> and press <strong>Get</strong> (or <strong>Install</strong>). The Store signs it and updates it for you.</p><figure class="guide-shot"><img class="guide-shot-img" src="/assets/guides/install-store-listing.png" alt="The Guilded Companion page in the Microsoft Store with the Get button" loading="lazy"><figcaption><span class="shot-soon">Screenshot coming soon: </span>the Store listing and its Get button.</figcaption></figure><details><summary>Store not an option? Use the direct download</summary><p><a href="{{COMPANION_DIRECT_URL}}">Download the installer ↓</a>. Run it. It is not code-signed, so Windows may say it <strong>protected your PC</strong>: press <strong>More info</strong>, then <strong>Run anyway</strong>. It then updates itself.</p><figure class="guide-shot"><img class="guide-shot-img" src="/assets/guides/install-smartscreen.png" alt="The Windows SmartScreen warning with More info and Run anyway" loading="lazy"><figcaption><span class="shot-soon">Screenshot coming soon: </span>SmartScreen after More info, Run anyway highlighted.</figcaption></figure></details></li>
<li class="start-step"><div class="start-head"><span class="start-num" aria-hidden="true">6</span><h3>Open it for the first time</h3></div><p>Start <strong>Guilded Companion</strong> from the Start menu. The <strong>Home</strong> page says <em>Welcome to Guilded.</em> and shows your next step. Close WoW, then press <strong>Set up WoW and the addon</strong>: the companion finds your WoW folder by itself and keeps the addon up to date. (Steps 1 to 3 already done? It simply recognises the addon.)</p><figure class="guide-shot"><img class="guide-shot-img" src="/assets/guides/install-companion-first-launch.png" alt="The companion Home page at first launch with the Set up WoW and the addon button" loading="lazy"><figcaption><span class="shot-soon">Screenshot coming soon: </span>companion Home on first launch, Set up WoW and the addon highlighted.</figcaption></figure></li>
<li class="start-step"><div class="start-head"><span class="start-num" aria-hidden="true">7</span><h3>Next: link your character</h3></div><p>Installed. The last thing to do is to connect your Discord account.</p><p><a class="button start-big" href="/guides/link/">Link your character <span aria-hidden="true">→</span></a></p></li>
</ol>

<h2>It did not work?</h2>
<div class="start-help"><details><summary>I do not see Guilded in the AddOns list</summary><p>Close WoW, and check that the folder is <code>Interface\AddOns\Guilded</code> with <code>Guilded.toc</code> directly inside, in the game folder of the version you launch (Battle.net: <strong>Options → Show in Explorer</strong>). Each WoW version has its own folder.</p></details><details><summary>Windows will not start the direct installer</summary><p>Press <strong>More info</strong>, then <strong>Run anyway</strong>. If your PC blocks it, use the Microsoft Store version instead.</p></details><details><summary>The companion cannot find WoW</summary><p>Open <strong>Link everything</strong> in the companion menu, or the settings, and press <strong>Choose WoW folder</strong>. Pick your World of Warcraft folder.</p></details><details><summary>I play on several WoW accounts</summary><p>Nothing to set up. When the companion finds Guilded's data on another account of the same WoW (WoW1, WoW2…), it asks once whether it is yours too. Press <strong>Yes, sync it too</strong> and it syncs that account as well; <strong>No, not mine</strong> is for a partner on the same PC, and it never asks again. Each account then has its own line on the <strong>Sync</strong> page and a switch under <strong>Settings → Your WoW folder</strong>. Log in once on each account and type <code>/reload</code> so WoW saves its data.</p></details></div>
