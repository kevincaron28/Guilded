# Guilded 9.1.2 — release notes (9 November 2026)

**One clear 3-step guide to the companion, and one profession name whatever the game language.** Protocol 2, WoW Forever only.

Real-client checks: docs/V8_5_0_RELEASE_ACCEPTANCE.md and docs/ZERO_SETUP_COMPANION.md.

## What changes for members

- **Three steps, same everywhere.** The addon (including `/guilded companion` and `/gdungeons companion`), the website, `/help` and the CurseForge page show the same 3 steps to install the companion. The Start page says no sign-in is needed.
- **Cooking = Cuisine.** Professions are stored under one English name, so French and English clients no longer appear as two different professions. The bot migration is already live; the addon side arrives with this release.
