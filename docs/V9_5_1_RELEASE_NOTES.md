# Guilded 9.5.1 release notes

Prepared 23 November 2026. Protocol 2, WoW Forever only. Addon fixes; the companion only changes its version number.

Real-client checks: docs/V9_5_1_RELEASE_ACCEPTANCE.md.

## Addon

- The Ready to promote alert has a small X. It stays hidden until the number of members ready for promotion changes, or until your next login (#1263).
- Invite now tries to send the guild invite right from your click. If WoW Forever refuses it, Guilded remembers that for this game build and shows the copy box, as before (#1263).
- When the game refuses a Guilded call without naming it, the problem list now shows which part of Guilded made the call (#1263).

## Companion

- Version 9.5.1, no functional change. The Microsoft Store keeps 9.5.0.0, which is in certification.
