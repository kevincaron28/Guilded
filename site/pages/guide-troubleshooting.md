<h1>Troubleshooting</h1>
<ul>
<li>Addon missing from the list: <a href="/guide/install/">check the install folder</a> and enable out-of-date addons.</li>
<li>Companion cannot see characters: the game must be closed once after install, then <code>/reload</code>.</li>
<li>A run is missing from the board: sync from the companion after the clear.</li>
</ul>
