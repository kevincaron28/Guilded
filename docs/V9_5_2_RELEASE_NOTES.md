# Guilded 9.5.2 release notes

Published 23 November 2026. Protocol 2, WoW Forever only. Addon changes; the companion only changes its version number.

Real-client checks: docs/V9_5_2_RELEASE_ACCEPTANCE.md.

## Addon

- The Crafting tab now shows the reagents of every recipe, with how many you have and need, without opening your profession window first (#1267).
- Invite on WoW Forever opens the copy box right away: copy the /ginvite line and paste it in chat. No more "blocked" popup (#1268).
- Ready to promote gives each member a Copy command button: paste the /gpromote line in chat. Done hides a row you handled another way, and Copy next command works with the Promote next key binding (#1268).

## Companion

- Version 9.5.2, no functional change. The Microsoft Store keeps 9.5.0.0, which is in certification.
