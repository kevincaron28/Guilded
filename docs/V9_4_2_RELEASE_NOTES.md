# Guilded 9.4.2 — release notes (19 November 2026)

**The data-loss audit fixes.** Published 19 November 2026. Protocol 2, WoW Forever only. Bot changes are already live.

Real-client checks: docs/V9_4_2_RELEASE_ACCEPTANCE.md. 9.4.2 is not yet confirmed on real clients.

## What changes for members

- **Milestones:** achievements no longer push out your level-ups and first clears.
- **Dungeons:** old run copies fill in missing guilds and roles; every run is sent in full.
- **Uploads:** big uploads go in parts, so nothing gets stuck; every duel, milestone and recipe arrives.
- **Crafting:** one bad order no longer hides the whole list.

## In short (English)

Guilded 9.4.2: nothing gets lost on the way to Discord anymore — milestones, runs, duels and recipes all arrive.

## En bref (français)

Guilded 9.4.2 : plus rien ne se perd en route vers Discord : jalons, donjons, duels et recettes arrivent au complet.
