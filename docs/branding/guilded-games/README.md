- `logo-400.png`: 400px listing logo derived from the original.

Logo prompt: original polished fantasy party-game emblem, two ivory dice with
gold beveled edges inside a gilded circular crest with teal enamel accents;
crisp hand-painted game UI style, transparent background, no lettering,
watermark, currency or casino chips.

Banner prompt: use that emblem as the exact logo reference, left-aligned on a
wide midnight-teal textured background with subtle golden sparks; gold title
"GUILDED GAMES", cream subtitle "Only the host needs the addon", small "ALPHA"
label; no fabricated game screenshots or additional logos.

Both images were generated with the built-in tool, not the API/CLI fallback.
The PNG size derivative and runtime TGA are deterministic format conversions.
