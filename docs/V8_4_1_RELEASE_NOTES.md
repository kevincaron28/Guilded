# Guilded 8.4.1 — Companion Link everything and console polish

A small release that brings the Windows companion (and Microsoft Store package)
up to date with the bot, which already runs these changes. Protocol stays 2.

- **Companion first run:** a single "Link everything" screen covers Discord
  sign-in, optional Battle.net and automatic character proof. The main screen
  shows a character table, big actions and plain linked-state wording.
- **Owner console:** redesigned server board and per-server pages.
- **Quick reference:** a new one-page member quick reference on the website.
- **Achievement cards:** redesigned WoW-style achievement share cards.
- **Guild rank:** the guild's WoW rank is shown where members expect it.

Existing published 8.4.0 artifacts are unchanged. Provider status and any
real-client checks are tracked in [the release acceptance checklist](V8_4_1_RELEASE_ACCEPTANCE.md).
