# Guilded 9.4.5 — release notes (20 November 2026)

Published 20 November 2026. Protocol 2, WoW Forever only. Bot changes are already live.

Real-client checks: docs/V9_4_5_RELEASE_ACCEPTANCE.md.

## What changes for members

- **Help:** "On my way" on a call for help now brings you onto the caller's layer; a key binding asks for a layer invite any time.
- **Officers:** the officer windows open side by side.
- **Duels:** duel time, damage, healing and health on the duel card.
- **Ready for the next WoW Forever hotfix:** your guild data stays put when realm names go blank.

## In short (English)

Guilded 9.4.5: layer help when you call for help, tidy officer windows, duel stats, and ready for the next Forever hotfix.
