# Guilded 9.1.4 — release notes (10 November 2026)

**Linking and dungeon fixes after the 9.1.3 retest.** Protocol 2, WoW Forever only.

Real-client checks: docs/V8_5_0_RELEASE_ACCEPTANCE.md and docs/ZERO_SETUP_COMPANION.md.

## What changes for members

- **`/gdungeons` and `/gdg` work with Guilded alone** and answer for guildmates' runs; dungeons-only members' runs reach the leaderboards through a guildmate.
- **Fewer in-game errors:** world map dots, no blocked guild reads, the welcome is retried, Invite buttons show a copy box.
- **Linking is safer:** the "Linked to Discord" line is per character; a link only lands on a server that knows your in-game guild; sign-in lists matching servers first; the companion can leave a server; stronger proof wins and unlinking detaches.
- **Guilded Clash** balance: 16 Health, Sudden Death (bot side; the phone app is separate).
