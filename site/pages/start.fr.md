<h2 id="joueur-title">Joueurs : trois étapes</h2>
<p>Gratuit. L’addon est la seule chose obligatoire.</p>
<ol class="start-list">
<li class="start-step"><div class="start-head"><span class="start-num" aria-hidden="true">1</span><h3>Installer l’addon</h3><span class="start-tag required">Obligatoire</span></div><p>Choisissez la version de WoW que vous jouez. Le bouton ouvre le téléchargement de cette version et indique où placer les fichiers.</p><div class="start-editions"><a class="button secondary" href="/editions/forever/?lang=fr">WoW Forever <span aria-hidden="true">→</span></a><a class="button secondary" href="/editions/classic-era/?lang=fr">Classic Era / Hardcore <span aria-hidden="true">→</span></a><a class="button secondary" href="/editions/classic-tbc/?lang=fr">Burning Crusade Classic <span aria-hidden="true">→</span></a><a class="button secondary" href="/editions/classic-mists/?lang=fr">Mists of Pandaria Classic <span aria-hidden="true">→</span></a><a class="button secondary" href="/editions/retail/?lang=fr">Retail <span aria-hidden="true">→</span></a></div><p class="small">Hardcore utilise le fichier Classic Era. Fermez WoW avant d’installer.</p></li>
<li class="start-step"><div class="start-head"><span class="start-num" aria-hidden="true">2</span><h3>Obtenir le compagnon</h3><span class="start-tag">Facultatif</span></div><p>Il envoie vos données de jeu enregistrées vers Discord et le site. Windows seulement. Sans lui, l’addon fonctionne quand même en jeu.</p><p><a class="button start-big" href="https://apps.microsoft.com/detail/9N680XX3QFL9">Obtenir sur le Microsoft Store <span aria-hidden="true">↗</span></a></p><p class="small">Le Store vous donne le dernier compagnon publié et le met à jour tout seul. <a href="https://github.com/kevincaron28/Guilded/releases/latest">Pas de Store ? Téléchargement direct sur GitHub</a> (non signé : Windows peut vous avertir).</p></li>
<li class="start-step"><div class="start-head"><span class="start-num" aria-hidden="true">3</span><h3>Se connecter avec Discord</h3><span class="start-tag">Un seul clic</span></div><p>Connectez-vous sur le site, et dans le compagnon si vous l’utilisez. Le lien de vos personnages et la synchronisation se font ensuite tout seuls.</p><p><a class="button start-big" href="/me/?lang=fr">Se connecter avec Discord <span aria-hidden="true">→</span></a></p></li>
</ol>
<h3>De quoi ai-je besoin ?</h3>
<div class="table-wrap"><table><thead><tr><th scope="col">Élément</th><th scope="col">Nécessaire ?</th><th scope="col">À quoi ça sert</th></tr></thead><tbody><tr><th scope="row">Addon</th><td><strong>Obligatoire</strong></td><td>Tout en jeu : EP/GP, butin, donjons, artisans.</td></tr><tr><th scope="row">Compagnon</th><td><strong>Facultatif</strong></td><td>Envoie les données de jeu vers Discord et le site. Windows seulement.</td></tr><tr><th scope="row">Bot Discord</th><td><strong>Seulement pour les propriétaires de serveur</strong></td><td>Inscriptions, classements et sondages dans votre Discord. Les membres ne l’installent pas.</td></tr></tbody></table></div>
<h3>Ça ne marche pas ?</h3>
<div class="start-help"><details><summary>L’addon n’apparaît pas en jeu</summary><p>Fermez complètement WoW, puis copiez le dossier <code>Guilded</code> dans <code>Interface/AddOns</code> de la version du jeu que vous lancez. Il doit contenir <code>Guilded.toc</code> (pas un deuxième dossier <code>Guilded</code>). Lancez WoW et cochez <strong>Charger les addons périmés</strong> si on vous le demande.</p></details><details><summary>Le site ou Discord n’affiche rien</summary><p>WoW n’enregistre vos données que si vous tapez <code>/reload</code> ou vous déconnectez. Faites-le, puis laissez le compagnon synchroniser.</p></details><details><summary>Mauvaise version ou mauvais dossier</summary><p>Chaque version de WoW a son fichier et son dossier de jeu. Vérifiez la version dans Battle.net, puis utilisez <em>Afficher dans l’Explorateur</em> pour trouver ce dossier.</p></details></div>

<section id="officier" class="start-path" aria-labelledby="officier-title">
<h2 id="officier-title">Officiers : le chemin le plus court</h2>
<p>Vous pouvez tout gérer en jeu avec l’addon seul. Discord est facultatif.</p>
<ol class="start-list"><li class="start-step"><div class="start-head"><span class="start-num" aria-hidden="true">1</span><p><strong>Installez l’addon</strong> et demandez à vos membres d’en faire autant. Partagez cette page : <a href="/start/?lang=fr">guilded.kcaron.top/start</a>.</p></div></li><li class="start-step"><div class="start-head"><span class="start-num" aria-hidden="true">2</span><p><strong>Fixez les règles en jeu.</strong> EP/GP, butin et cores de raid : <a href="/docs/EPGP_GUIDE.html#fr">guide EP/GP</a>.</p></div></li><li class="start-step"><div class="start-head"><span class="start-num" aria-hidden="true">3</span><p><strong>Envie de Discord ?</strong> Demandez au propriétaire du serveur d’ajouter le bot (l’onglet serveur explique comment). Lancez ensuite le <a href="/companion/">compagnon</a> et connectez-vous avec Discord pour que les données de votre guilde arrivent sur Discord. Au moins un officier doit le lancer.</p></div></li><li class="start-step"><div class="start-head"><span class="start-num" aria-hidden="true">4</span><p><strong>Passez en public quand vous êtes prêt :</strong> <code>/guildpage create</code>, puis <code>/guildpage publish</code>.</p></div></li></ol>

<h2 id="serveur-title">Propriétaires de serveur : ajoutez le bot</h2>
<p>Bot hébergé gratuit. Il faut la permission de gérer le serveur.</p>
<ol class="start-list"><li class="start-step"><div class="start-head"><span class="start-num" aria-hidden="true">1</span><p><strong>Ajoutez le bot</strong> avec le bouton ci-dessous.</p></div></li><li class="start-step"><div class="start-head"><span class="start-num" aria-hidden="true">2</span><p><strong>Lancez <code>/setup start</code></strong> dans Discord. Choisissez votre langue et vos salons. <code>/setup start status:true</code> montre ce qui manque.</p></div></li><li class="start-step"><div class="start-head"><span class="start-num" aria-hidden="true">3</span><p><strong>Vous êtes tout de suite en Guilded Lite.</strong> La synchronisation de l’addon, l’EP/GP et les saisons s’ouvrent après l’approbation de votre serveur : <a href="/docs/HOSTED_PILOT.html#fr">guide du bot hébergé</a>.</p></div></li><li class="start-step"><div class="start-head"><span class="start-num" aria-hidden="true">4</span><p><strong>Dites à vos membres</strong> d’ouvrir <a href="/start/?lang=fr">cette page</a>. Les officiers lancent ensuite le compagnon.</p></div></li></ol>
