# Guilded 9.5.4 release notes

Prepared 23 November 2026. Protocol 2, WoW Forever only. Addon changes; the companion only changes its version number.

Real-client checks: docs/V9_5_4_RELEASE_ACCEPTANCE.md.

## Addon

- Ready to promote no longer hides Roster admin, and the dungeons window opens in front.
- Crafting shows how many of each reagent you have in your bags.
- Simpler navigation: Dungeons and Roster admin open directly, one row of Officer tabs, a cleaner Home once you are linked, grouped Settings with clearer names.
- Small fixes: Season 1 wording, readable raid times, wider Gear columns, a clear line when nobody has EP/GP, tooltips that no longer cover their tabs.
- Layer auto-invite is back off for anyone 9.5.0 switched on; turn it on again in Layer if you want it (#1278).

## Companion

- Version 9.5.4, no functional change. The Microsoft Store keeps 9.5.0.0, which is in certification.
