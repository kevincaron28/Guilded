# Guilded 8.0.1 Release

Language completion for the 8.0 launch. All five WoW edition builds of Guilded
and Guilded Dungeons receive the same reviewed catalogue. Protocol remains 2.

- German and Spanish cover all 1,052 catalogued addon strings, up from 149 each.
  This includes guild setup, permissions, loot, EPGP, dungeon scores, calendar,
  availability/privacy, roster administration and GRM history/error messages.
- Added 42 previously uncatalogued UI strings in French, German and Spanish.
  Corrected French accents and the raid-roster meaning of “Main”; shortened
  Spanish controls that clipped in the offline window checks.
- Formatting checks preserve ordered placeholders, padded timers, percentages,
  named template fields and links. Command syntax and confirmation phrases stay
  executable in every language. Unknown external text retains its original value.
- Retains the final 8.0 bot/web corrections for edition-aware navigation/sign-in,
  public-season transactions and browser-companion redirects.

The companion, website and Discord bot remain English/French. German/Spanish
completion here applies to the addons. The linguistic review is model-assisted;
it does not claim an independent native-speaker certification.

## Windows and updates

Use the free [Microsoft Store companion](https://apps.microsoft.com/detail/9N680XX3QFL9)
for Store-signed Windows distribution and Store-managed updates. The installed
8.0.0.0 baseline passed cryptographic signature/certificate-chain and Windows
package-status checks on 28 October. New Store versions are signed and delivered
after Microsoft completes their separate certification process.

The optional standalone GitHub EXE remains unsigned and explicitly labelled.
Store signing does not sign that EXE. The project keeps PolyForm Noncommercial
1.0.0; no paid signing service, license change or self-signed trust installation
is introduced. Existing published 8.0 downloads remain intact.

Keep SavedVariables and connection data when updating. No score, ledger, role,
privacy default, eligibility policy or historical season is reset.

Validation, publication and remaining game evidence are recorded in the
[launch completion checklist](V8_0_1_LAUNCH_COMPLETION.md).
