# Guilded 9.5.5 release notes

Prepared 23 November 2026. Protocol 2, WoW Forever only. Addon changes; the companion only changes its version number.

Real-client checks: docs/V9_5_5_RELEASE_ACCEPTANCE.md.

## Addon

- The officer Gear table shows every member again.
- The Settings switches no longer overlap.
- Open raids shows a readable snapshot time.
- The dungeons window no longer covers the main window (#1281).

## Companion

- Version 9.5.5, no functional change. The Microsoft Store keeps 9.5.0.0, which is in certification.
