## Comment fonctionne le butin ?

Les deux cores utilisent **la priorité EPGP avec des prix fixes**. Chaque objet a un prix en GP ; parmi les joueurs intéressés, la priorité EPGP départage l'attribution. Chaque core possède **sa propre réserve de points** : choisissez le bon core lorsque vous consultez le classement.

Les règles effectives vérifiées le 14 octobre sont les mêmes pour les deux cores :

| Règle | Valeur |
| --- | --- |
| Présence | 10 EP |
| Arrivée tardive | 5 EP |
| Boss vaincu | 5 EP |
| Bonus de raid terminé | 10 EP |
| GP de base | 100 |
| Décroissance configurée | 10 % |
| Coût en spécialisation secondaire | 50 % du prix GP |
| Minimum d'EP pour la priorité | Désactivé |

Les officiers peuvent modifier ces règles. Le compagnon et Discord présentent les valeurs actuelles ; cette page ne promet pas une fréquence de décroissance ni une attribution automatique de tous les bonus.

## Consulter les classements EPGP actuels

Dans le Discord de Quebec Gold, lancez `/epgp leaderboard`, puis choisissez le core dans l'option **core**. Utilisez la liste proposée par Discord :

- **Les Pulliticiens** pour le classement du core Hyjal.
- **Les Aggros Anonyme** pour le classement du core Barrow Deeps.

Les classements nominatifs restent dans l'espace des membres. Le site public ne publie ni soldes individuels ni listes de personnages.
