# Guilded 9.5.3 release notes

Prepared 23 November 2026. Protocol 2, WoW Forever only. Addon changes; the companion only changes its version number.

Real-client checks: docs/V9_5_3_RELEASE_ACCEPTANCE.md.

## Addon

- A lighter saved file: dungeon runs no longer keep where players died or the squares they walked through. Nothing showed them since 9.3.8; your saved runs drop them at your next login (#1275).
- At most 300 stored dungeon runs (#1274).
- The Backup window Close button is translated (#1272).

## Companion

- Version 9.5.3, no functional change. The Microsoft Store keeps 9.5.0.0, which is in certification.
