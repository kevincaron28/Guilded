# Le compagnon Windows

Le compagnon est facultatif : l’addon fonctionne seul, et vos donjons et vos duels peuvent arriver aux
classements par le compagnon d’un autre joueur. C’est la façon la plus rapide de lier vos personnages
à Discord (sans lui, envoyez au bot Guilded le nom complet de votre personnage en message privé), et
il se synchronise tout seul. Il est gratuit, pour Windows 10 et 11.

## L’installer

1. [Téléchargez-le](/download/?lang=fr#companion), ou prenez-le dans le Microsoft Store, où il porte le
   nom **Guild Sync Companion**.
2. Lancez le fichier. Si Windows dit qu’il a protégé votre PC, choisissez **Informations
   complémentaires → Exécuter quand même** (l’installateur du site n’est pas signé).
3. Laissez-le ouvert. Il démarre avec Windows et reste près de l’horloge. Il trouve World of Warcraft,
   installe ou met à jour l’addon Guilded et choisit le serveur Discord de votre guilde d’après votre
   guilde en jeu.
4. Dans WoW, tapez `/reload` (ou déconnectez-vous). La ligne **Dernière synchronisation** devient verte
   avec l’heure.

## Ce que montre la fenêtre

| Ligne ou bouton | Ce que ça veut dire |
| --- | --- |
| **World of Warcraft** | Le dossier du jeu utilisé. Introuvable ? Appuyez sur **Choisir le dossier** et prenez le dossier World of Warcraft qui contient `_forever_`. |
| **Addon Guilded** | L’addon est installé et à jour. |
| **Dernière synchronisation** | Le dernier envoi de vos données. **Synchroniser maintenant** les envoie tout de suite. |
| **Synchronisé en tant que** | Votre nom Discord après la connexion. **Se connecter avec Discord** est facultatif : il confirme vos personnages et ouvre les messages Discord. |
| **Avancé** | **Réparer**, **Réinstaller l’addon**, **Comptes WoW**, **Tous les problèmes**, **Activité** et **Copier le rapport d’assistance**. |

## Mises à jour

Le compagnon se met à jour tout seul : une nouvelle version s’installe quand vous le quittez ou le
redémarrez, ou tout de suite avec **Mettre à jour**. La version du Microsoft Store est mise à jour par
le Store.

## Plusieurs comptes WoW sur un même PC

Quand il trouve les données de Guilded sur un autre compte, il demande si ce compte est à vous :
**Oui** le synchronise aussi, **Non** le laisse de côté (pour une personne qui partage votre PC). Vous
pouvez changer la réponse dans **Avancé → Comptes WoW**.
